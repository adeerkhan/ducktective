## Finding

**Confirmed cause:** Opening host selection honored the preferExternal flag with no distance guard (pre-fix openingCuts.ts host picker, line 288), so an opening whose adjacent wall was interior was clipped to an exterior wall metres away. The lintel strip then spanned that far wall (Door 09: 0.90 m wide x 18.66 m deep) and the frame floated up to 4.64 m off its host (depthOffsetM). Verified by a property check that fails on 6e55c0f0 (43 anomalies) and passes on 9095f188 (0 anomalies, maxDepthOff 0.025 m); the control (a synthetic clean wire through the same check) passes.
